# 作业 5：递归调用

## 实现思路

程序按 `F(n)=F(n-1)+F(n-2)` 递归求解，基础值为 `F(0)=0`、`F(1)=1`。使用缓存保存已经算出的项，避免重复展开相同子问题，使 `n=100` 时也能较快完成计算。

## 编程中遇到的问题

- 结果溢出。 `F(100)` 需要 69 位，超过单个寄存器和 64 位整数的范围。因此使用 5 个 16 位字保存结果，通过 `DI:DX:CX:BX:AX` 返回。
- 递归覆盖寄存器。 第二次调用会覆盖第一次调用的结果。程序先把 `F(n-1)` 保存到本层栈帧，再计算 `F(n-2)`，并在返回时恢复 `BP` 和 `SI`。
- 多字加法与输出。 加法从低字开始，使用 `ADD` 和 `ADC` 逐字传递进位。输出时对整个多字整数反复除以 10，收集余数并倒序排列，得到十进制字符串。

## 栈空间分析

程序分配 `1000H`，即 4096 字节栈空间，并在首次调用前初始化栈指针。每层递归占用 18 字节，包括返回地址、保存的 `BP`、`SI` 和局部变量。

`n=100` 时最多同时存在 100 层，递归栈占用为 `100×18=1800` 字节，剩余空间用于中断等额外开销。近调用 `CALL` 压入 2 字节返回地址，函数退出时释放局部空间、恢复寄存器，再由 `RET` 弹出返回地址。

单步跟踪时需要同时观察 `IP` 和 `SP`，区分调用次数与同时存在的栈帧数。计算栈容量应依据最大递归深度。

## 反汇编体会

C 版本同样使用多字整数和递归缓存。反汇编中可以看到两次递归 `CALL`，以及参数和局部变量在栈帧中的保存方式。编译器还把除以常数 10 转换为乘法和移位，因此添加注释时需要结合指令的实际作用理解源码。
